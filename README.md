# AI 学习项目心得记录

> 用 AI 工具（WorkBuddy / 各类模型）做出的学习项目，这里统一沉淀**作品代码 + 过程与心得**。

## 仓库定位

- **一个仓库管理所有内容**：作品代码、复盘笔记、模板都放在本仓库，按 `projects/<项目名>/` 组织。
- **只有大型项目才单独建仓库**：当某个项目成长到需要独立迭代 / 协作 / CI 时，再拆出去建专属仓库，并在下方索引注明外部链接。
- 目标：便于跨项目复盘、复用方法、回顾成长轨迹，又不让小项目散落成孤岛。

## 结构约定

- 每个项目放在 `projects/<项目名>/`：
  - `<项目名>.html`（或源码）—— 作品本身
  - `LEARNING.md` —— **详细工程版**复盘（踩坑、验证、代码细节）
  - `<项目名>.md` —— **AI 使用复盘**（角度不同、更轻，记"怎么用 AI 做出来"）
  - `_extract.js` / `_test.js` —— 可复跑的回归测试脚手架（如适用）
- 新项目直接复制根目录 `_LEARNING_TEMPLATE.md` 为 `projects/<项目名>/<项目名>.md` 后填写。
- 跨项目的通用方法、模板、索引都放在仓库根目录。
