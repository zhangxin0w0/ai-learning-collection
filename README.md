# AI 学习项目心得记录

> 用 AI 工具（WorkBuddy / 各类模型）做出的学习项目，这里统一沉淀**过程与心得**，与项目自身的代码仓库分离。

## 项目demo用文件夹区分，大型项目单独建仓库

项目仓库（如 `jicshi-radar`）负责展示作品和部署；本仓库负责记录"我是怎么用 AI 学会 / 做出来的"——便于跨项目复盘、复用方法、回顾成长轨迹。

## 结构约定

- 每个项目一个 Markdown 文件，命名 `<项目名>.md`，写在仓库根目录。
- 新项目直接复制 `_LEARNING_TEMPLATE.md` 为 `<项目名>.md` 后填写。
- 项目自身的**详细工程版**心得放在其代码仓库的 `LEARNING.md`；本仓库侧重"AI 使用复盘"，角度不同、不重复。
